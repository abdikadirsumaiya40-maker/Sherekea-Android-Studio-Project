# Sherekea Livestock — Android Studio Project

Native Flutter Android project for the Sherekea livestock marketplace.

Includes Buyer, Seller and Admin experiences; phone/password registration and login UI; livestock search and categories; exact listing images; favorites; orders; M-Pesa and Cash payment selection; seller verification; seller dashboard; livestock photo upload entry point; admin controls; notifications; and a cute Kenya-focused livestock design.

## Run
1. Install Flutter and the Flutter/Dart Android Studio plugins.
2. Open this folder in Android Studio.
3. Run `flutter pub get`.
4. Connect an Android phone/emulator.
5. Run `flutter run`.

This is the Android UI/prototype layer. Live FastAPI/PostgreSQL authentication, cloud image storage and Safaricom M-Pesa credentials still need to be connected through a backend before production.
